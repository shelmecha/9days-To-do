Fonts in this directory
=======================

  ms_sans_serif.woff2
  ms_sans_serif_bold.woff2

Pixel-accurate recreations of the Windows 95 UI font, drawn at a design size of 11px.

--------------------

- ShareAlike (§4(b)) binds Adaptations. Bundling an unmodified font inside an
  application makes a Collection, which the licence explicitly states "will not
  be considered an Adaptation" — so it does not impose any licence on this app's
  own source.
- Conversion from TTF to WOFF2 is permitted under §3: the granted rights include
  "the right to make such modifications as are technically necessary to exercise
  the rights in other media and formats".
- FONTSTRUCT-readme.txt is redistributed alongside the fonts because the FontStruct
  download terms require it: "If you redistribute the font file in this archive, it
  must be accompanied by all the other files from this archive, including this one."
